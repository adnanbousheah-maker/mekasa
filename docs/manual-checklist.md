# قائمة الفحص اليدوي

جرّب كل سطر وعلّم عليه. الأفضل على جوال حقيقي للموظفين، ولابتوب للأدمن. محلياً: `npm run db:verify` ثم `npm run dev`، والأرقام التجريبية بـ `scripts/seed-staff.ts` (0790000001 أدمن، 02 الصويفية، 03 الجبيهة، 04 دابوق، 05 المصنع: الإخراج وأمين المستودع).

## المرحلة 1: الأساس والجرد

### الدخول والموظفين
- [ ] الدخول برقم الجوال والرمز (4 أرقام للكل).
- [ ] رمز غلط 5 مرات → رسالة القفل 15 دقيقة. نفس الرسالة لرقم مش مسجل.
- [ ] الأدمن بيضيف موظف، بيختار الموقع والأدوار، وبيشوف الرمز مرة وحدة.
- [ ] "رمز جديد" بيبطّل الرمز القديم.
- [ ] إيقاف موظف وهو فاتح التطبيق على جوال ثاني → بيطلع فوراً لما يكبس أي شي.
- [ ] ما بتقدر توقف آخر أدمن فعّال.
- [ ] تحويل موظف لأدمن بيعطيه رمز جديد.

### الإعدادات
- [ ] تعديل اسم صنف بالعربي وعدد القطع بالكيكة، والحفظ لحاله لما تطلع من الحقل.
- [ ] فراغ "قطع بالكيكة" للصنف = الرقم العام.
- [ ] إضافة موعد جرد وإيقافه، ورجعة نفس الساعة.
- [ ] تغيير الإعدادات العامة (موافقة الطلبات، التحويل، الإرجاع، الساعات، مدد الحياة).
- [ ] كل تعديل ظاهر بسجل التعديلات.

### الجرد اليدوي
- [ ] الفرع: كيكات + قطع لكل صنف بأزرار + و −، مراجعة، تأكيد.
- [ ] أول جرد بالموقع = رصيد افتتاحي (ما بيطلع استهلاك).
- [ ] المصنع: جرد أعمى بأرقام الدفعات (ما في كمية متوقعة).
- [ ] بعد التأكيد الموظف ما بيقدر يعدل.
- [ ] الأدمن بيصحح سطر من **الجرودات** مع سبب إجباري، والقيمة الأصلية بالسجل.

### الجرد بالصورة
- [ ] اطبع الفورم من **الإعدادات → مواعيد الجرد** (A4، QR، المربعات، الأصناف).
- [ ] عبّي الفورم بالقلم وصوّره من الجوال → الأرقام بتطلع، والمش أكيدة برتقالي.
- [ ] صحح رقم وأكّد. الأدمن بيشوف الصورة جنب الأرقام والتصحيح.
- [ ] صورة مش واضحة أو فورم غلط → رسالة واضحة وإدخال يدوي.

### المواعيد والإشعارات
- [ ] "فعّل الإشعارات" بالرئيسية (آيفون: من التطبيق المضاف للشاشة الرئيسية).
- [ ] تذكير قبل الموعد، و"متأخر" بعد المهلة للموقع وللأدمن.
- [ ] الشريط البرتقالي بالرئيسية وقت الجرد.

### التالف
- [ ] صنف، كيكة أو قطعة، سبب، و"غيره" بده ملاحظة.
- [ ] صورة اختيارية بتنرفع وبتبين للأدمن.
- [ ] بالمصنع بيطلب رقم الدفعة.

### لوحة الأدمن
- [ ] النظرة العامة: المواقع، بدها انتباهك، استهلاك الأسبوع.
- [ ] الستوك والاستهلاك: "3 كيكات + 5 قطع"، والأرقام المستحيلة بالأحمر.
- [ ] تصدير Excel من كل جدول ويفتح عربي ومرتب.

## المرحلة 2: الحركة بين المواقع
- [ ] الفرع بيطلب: الكمية المقترحة = الحد − الموجود. الحالة "مرسل".
- [ ] مع تفعيل موافقة الطلبات: "بانتظار الموافقة" والأدمن بيوافق أو بيرفض.
- [ ] الإخراج بيبلش بكميات الطلب، وبتقدر تزيد أو تنقص أو تضيف.
- [ ] FEFO: الدفعة الأقدم أول. اختيار أحدث → تنبيه أحمر لازم تأكده، وبيبين بالسجل.
- [ ] دفعة منتهية ما بتطلع، والستوك الناقص بيمنع الإخراج.
- [ ] الفرع بيستلم سطر سطر. فرق → ملاحظة، والأدمن بيشوفه أحمر بـ **الطلبيات**.
- [ ] الفرق بين الطلب والإخراج بالأزرق.
- [ ] إخراج ما انستلم بعد 3 ساعات → تنبيه.
- [ ] التحويل بين فرعين.
- [ ] مع تفعيل الإرجاع: الفرع بيرجّع، وأمين المستودع بيقرر رجوع للستوك أو تالف.
- [ ] تسجيل الإنتاج لدفعة اليوم (أكثر من مرة باليوم)، ولوحة المصنع: إنتاج اليوم مقابل الجرد.
- [ ] رقم اليوم ولونه صح (السبت 1 … الجمعة 7).
- [ ] تنبيه "قرب يخلص" برئيسية الفرع.
- [ ] الحد المطلوب من الإعدادات.

## المرحلة 3: المواد الأولية
- [ ] استلام من مورد بوحدة ثانية (كيس = 25 كيلو) مع صورة فاتورة.
- [ ] صرف للإنتاج.
- [ ] جرد المواد، وأول جرد رصيد افتتاحي.
- [ ] "بيكفي كم يوم" و"تحت الحد الأدنى" بالرئيسية وبالنظرة العامة.
- [ ] الأدمن بيضيف مادة وتحويل وحد أدنى، وبيوقف مادة.

## المرحلة 4: مساعد الذكاء الاصطناعي
- [ ] "قديش في Classic Choco بالصويفية؟" → رقم مع المصدر.
- [ ] "مين ما جرد اليوم؟"، "شو الطلبيات المعلقة؟"، "قديش التالف هالأسبوع؟".
- [ ] سؤال بالصوت (Chrome) باللهجة.
- [ ] سؤال برا ميكاسا → "أنا بساعدك بس بأمور ميكاسا".
- [ ] طلب تعديل ("زيد الستوك") → بيرفض، ما بيعدل شي.
- [ ] الموظف العادي ما بيقدر يفتح `/admin/ai`.

## ملاحظات فريق ميكاسا (25 أكتوبر)
- [ ] **الطلبية المقترحة:** بعد كم أسبوع جرد، الأرقام بشاشة الطلب = معدل استهلاك نفس يوم بكرا ناقص الموجود. بدون جرد بهالأيام = الحد المطلوب.
- [ ] **صنف منسي:** صفّر صنف مقترح وراجع الطلب → "هالصنف انت ما طلبته"، وابعت. خلال دقيقة بيوصل إشعار للأدمن، وتفاصيل الطلب بلوحة الأدمن فيها "ما طلبوا أصناف مقترحة".
- [ ] **الحد الأدنى:** من الإعدادات ← الحد المطلوب، عبّي "الأدنى" لصنف. بعد جرد تحته: بانر أحمر بالفرع، وتنبيه بلوحة الأدمن، وإشعار مرة باليوم.
- [ ] **التوالف عند الاستلام:** الإخراج فيه اسم السائق، والاستلام ما بيتأكد بدون "فحصت البضاعة قدام السائق". التالف بينسجل تالف بالفرع.
- [ ] **جرد المواد من Excel:** نزّل القالب، عبّيه (كود، اسم، تعبئة، كمية)، ارفعه، شوف الملخص، وأكّد. المواد الجديدة بتنضاف.
- [ ] **التغليف:** ضيف مواد من الإعدادات ← التغليف. أمين التغليف (0790000006 محلياً) بيجرد المستودع، الفرع بيطلب من "تغليف"، الأمين بيطلّع، والفرع بيستلم. أعطِ دور "أمين التغليف" لموظف بفرع وتأكد إنه بيشوف المستودع.

- [ ] **توزيع اليوم:** خلّي فرعين يطلبوا نفس الصنف وفي دفعة قديمة ما بتكفي الكل. من "طلبات الفروع" ← "توزيع اليوم": القديم بيتوزع على الفرعين، وبتطلّعهم مع بعض.
- [ ] **مدة حياة لكل صنف:** من الإعدادات ← الأصناف، حط 14 لصنف. بجرد المصنع بيطلب تاريخ بدل رقم، وبالإنتاج بيقول اكتب التاريخ.

## عام
- [ ] كل الأزرار كبيرة ومريحة بالجوال، وما في قوائم مخفية للموظفين.
- [ ] موظف الفرع ما بيشوف غير فرعه (جرّب تفتح رابط استلام لفرع ثاني).
- [ ] الإضافة للشاشة الرئيسية بتفتح التطبيق بدون شريط المتصفح.
