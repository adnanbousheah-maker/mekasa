# التصميم — مرجع للشاشات

هاد المجلد فيه التصميم المعتمد لكل شاشات التطبيق. كل ملف `.dc.html` هو شاشة وحدة.

## كيف تستخدمه
- **هاد مرجع مش كود جاهز.** خذ منه الترتيب، والمسافات، والألوان، والأحجام، والنصوص العربية كما هي. وابني الشاشة الحقيقية بـ Next.js وTailwind حسب CLAUDE.md.
- الملفات ما بتشتغل لحالها بالمتصفح، لأنها مكتوبة لأداة التصميم. اقرأ الـ HTML والـ inline styles مباشرة.
- تجاهل وسوم `<x-dc>` و`<helmet>` و`<sc-for>` و`<sc-if>` و`<dc-import>`، وتجاهل كلاس `DCLogic` بالسكربت. البيانات اللي بالسكربتات أمثلة للعرض بس، مش بيانات حقيقية.
- `<sc-for>` معناها قائمة بتتكرر، و`<sc-if>` معناها شي بيظهر حسب حالة، و`<dc-import name="AdminNav">` معناها القائمة الجانبية من `admin/AdminNav.dc.html`.
- اللوجو بالتصميم رابطه `/_blob/…`. بالمشروع استعمل `public/logo.jpg` (نسخته هون: `logo.jpg`)، مع `mix-blend-mode: multiply` مشان خلفيته البيضا تذوب بالخلفية.
- مقاس الجوال بالتصميم 390×844. لوحة الأدمن 1440 عرض، ومرنة (القائمة الجانبية بتنزل فوق بالجوال).

## الشاشات
### موظف الفرع (`branch/`)
| الملف | الشاشة |
| --- | --- |
| Login | تسجيل الدخول: رقم جوال + رمز 4 أرقام |
| Main | الرئيسية: تذكير الجرد، تنبيه قرب الانتهاء، جرد/استلام/طلب، تالف، طلبياتي |
| CountMethod | الجرد: اختيار صورة أو يدوي |
| CountCamera | تصوير الفورم، وحالة "عم نقرأ الأرقام" |
| CountConfirm | تأكيد الأرقام: كيكات وقطع لكل صنف، والمش أكيد برتقالي |
| CountDone | نجاح الجرد |
| Order | الطلب من المصنع مع الكمية المقترحة من الحد المطلوب، ونافذة مراجعة |
| Orders | طلبياتي: طلبت مقابل طلع، والحالات |
| Receive | الاستلام حسب الإخراج، مع "كنت طالب" و"صنف إضافي" والفروقات |
| Waste | تسجيل تالف |

### المصنع والمستودع (`factory/`)
| الملف | الشاشة |
| --- | --- |
| FactoryHome | الرئيسية: أزرار كل أدوار الموظف وتنبيهات |
| FactoryRequests | طلبات الفروع، والإخراج اللي ما انستلم |
| Dispatch | الإخراج: الكميات من الطلب، الدفعات بأرقام الأيام، تنبيه الأقدم أولاً |
| Production | تسجيل إنتاج اليوم |
| FactoryCount | جرد المصنع حسب رقم الدفعة (جرد أعمى) |
| RawMaterials | المواد الأولية والحد الأدنى |
| RawMove | استلام وصرف مواد مع تحويل الوحدات |

### لوحة الأدمن (`admin/`)
| الملف | الشاشة |
| --- | --- |
| AdminNav | القائمة الجانبية (مكوّن مشترك) |
| AdminOverview | نظرة عامة: المواقع، التنبيهات، الاستهلاك، الطلبات |
| AdminStock | الستوك والاستهلاك: أصناف × مواقع، والحد المطلوب |
| AdminOrders | الطلب والإخراج والاستلام جنب بعض، والتحويلات |
| AdminCounts | تفاصيل جرد مع صورة الفورم وسجل التعديلات |
| AdminFactory | دفعات المصنع حسب رقم اليوم، والإنتاج مقابل الجرد |
| AdminRaw | المواد الأولية: بيكفي كم يوم، والحركات |
| AdminWaste | تقرير التالف |
| AdminSettings | الأصناف وعدد القطع، الحد المطلوب، مواعيد الجرد، إعدادات عامة |
| AdminStaff | الموظفين والأدوار والإيقاف |
| AdminAI | مساعد الذكاء الاصطناعي بالصوت |
